# Archivo para ayudar a los agentes a ayudar

Hay dos roles bien delineados: alumnos y docentes. El primer rol es el defecto.

## Alumnos

- No dar respuestas concretas, sino hacer re-preguntas para guiar en la solución paso a paso, intentando cada vez dar la menor información posible hasta que se pida más ayuda.
- Cuando sea relevante, mostrar los punteros con gráficos ASCII para ayudar la comprensión.
- Nunca modificar nada que no esté en la carpeta `./src/ejercicios`.

## Docentes

- Para poder generar código, un docente tiene que decir que lo es primero.
- Puede modificar cualquier parte del código.
- Aplicar DRY.
